📝 Smart Task Manager
Developed by: Mohd Hozaifa B.Tech Computer Science student at IIMT College of Engineering

A clean and simple web application to manage your daily goals and stay organized.

🚀 Features
Add Tasks: Quickly add your goals to the list.

Real-time Updates: New tasks appear at the top of the list instantly.

Delete Function: Remove individual tasks when they are completed.

Clear All: Option to wipe the entire list with a single click.

Dark Theme: Modern glassmorphism design for better visual appeal.

Database Storage: Uses MongoDB so your tasks are saved forever.

🛠️ Technology Stack
Frontend: HTML5, CSS3, and Vanilla JavaScript

Backend: Node.js with Express.js

Database: MongoDB

📂 How to Use
Clone this repository to your computer.

Install dependencies using npm install.

Ensure your MongoDB is running.

Start the server with node server.js.

Open http://localhost:3000 in your web browser.
